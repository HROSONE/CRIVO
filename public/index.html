SOBRE O PROJETO

Um cérebro próprio,
em construção.

O CRIVO é um experimento em Python. Ele combina recuperação de textos escritos previamente com relações lógicas verificáveis. Uma rede neural classificadora própria é opcional quando os pesos compatíveis estão instalados.

ConhecimentoBase local cadastrada
RaciocínioGrafo simbólico próprio
PrivacidadeSem armazenamento de conversas no servidor
LimiteNão é um LLM nem inteligência geral

Nesta interface o histórico curto é reenviado a cada pergunta para preservar o contexto entre requisições; não há login nem armazenamento permanente.
